# Application mobile

React Native + Expo SDK 58 + TypeScript. SDK 58 cible React Native 0.88 et React 19.3 ; son outillage requiert Node 22.13+ (ou Node 24.3+). Le prototype démarre en paysage pour privilégier le plateau à quatre joueurs. Le verrouillage d'orientation sera rendu conditionnel par écran lorsque les vues portrait (collection/deckbuilding) seront ajoutées.

Le plateau actuel est une maquette fonctionnelle de structure visuelle, pas encore connecté au moteur.
